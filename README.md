# ArtisanROM - Advanced Edition
* **Branch:** feat_eth_tethering
* **Basis:**  Android 16 / One UI 8.0

### System-Erweiterung: Ethernet_Tethering CLI
Diese Entwicklung integriert das native System-Kommando `eth_tethering` zur Steuerung des Ethernet-Tetherings über eine Framework-Schnittstelle.

### Syntax und Verwendung:
* **Hilfe-Anzeige:** `eth_tethering help`
* **Ethernet_Tethering EIN:** `eth_tethering on`
* **Ethernet_Tethering AUS:** `eth_tethering off`
